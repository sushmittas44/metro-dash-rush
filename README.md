# Metro Dash Rush

Create a fast-paced 3D endless runner game set in a vibrant subway system. The player controls a young character sprinting along railway tracks while avoiding moving trains, barriers, tunnels, and other obstacles.

Core gameplay:

Swipe or use arrow keys to move left and right, jump, and slide.

Collect coins and power-ups while running.

Include power-ups such as magnet, jetpack, shield, and speed boost.

Gradually increase the running speed and difficulty.

Add randomly generated tracks and obstacles so every run feels different.

Include a score, coin counter, distance meter, and high-score system.

Add missions and achievements to encourage replayability.

Create colorful environments with trains, stations, tunnels, advertisements, graffiti, and city scenery.

Add smooth character animations, camera movement, particle effects, sound effects, and energetic background music.

Include a game-over screen with score, distance, coins collected, and a restart button.

Use original characters, environments, names, and visual assets rather than copying copyrighted Subway Surfers characters or artwork.

Make the controls responsive, the gameplay visually polished, and the experience suitable for mobile and desktop.
